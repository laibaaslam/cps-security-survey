# Security in Cyber-Physical Systems

A survey paper on the security of cyber-physical systems (CPS), written at the National University of Computer and Emerging Sciences (FAST-NUCES), Lahore, Pakistan, in 2023.

**Authors:** Suniya Ehsan and Laiba Aslam

**Paper (PDF):** [Security_in_Cyber_Physical_Systems_Ehsan_Aslam_2023.pdf](Security_in_Cyber_Physical_Systems_Ehsan_Aslam_2023.pdf)

## Summary

The paper introduces cyber-physical systems, builds a knowledge base of CPS security threats, reviews research on threat analysis and security improvements, and compares existing security solutions with recommendations for future research.

## Topics covered

- CPS architecture and the layers where attacks happen
- Threat analysis methods, including STRIDE/DREAD threat modelling, fault and attack trees, and reinforcement-learning attack graphs
- Comparison of countermeasures, including physics-based sensor fingerprinting (NoiSense)
- Open security challenges and future research directions
